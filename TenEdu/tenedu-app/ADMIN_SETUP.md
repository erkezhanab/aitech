# TeńEdu Админка — Шаг 6

## Структура

Админка находится по маршруту `/admin` и имеет 5 разделов:

### 1. **Дашборд** (`/admin`)
Главная страница с статистикой:
- Барлық пайдаланушылар (всего пользователей)
- Ағымды пайдаланушылар (активных пользователей)
- Аяқталған модульдер (завершённых модулей)
- Орташа баға (средний рейтинг)

### 2. **Контент** (`/admin/tracks`)
Конструктор слайдов и модулей:
- Развёрнутый список треков
- Просмотр модулей и слайдов
- Редактирование слайдов (4 типа):
  - **Титульный слайд** — заголовок + тақырыбы
  - **Чек-лист** — список пункттар
  - **Контентный слайд** — мәтін + сурет
  - **Резюме** — итоговый слайд
- Кнопки редактирования, удаления, добавления

### 3. **Тесты** (`/admin/tests`)
Конструктор тестов:
- Список всех тестов (квиз-ов)
- Просмотр вопросов в каждом тесте
- Создание новых тестов (до 10 вопросов):
  - Single choice (бір таңдау)
  - Multiple choice (көп таңдау)
- Функции: редактировать, копировать, удалять

### 4. **Статистика** (`/admin/users`)
Аналитика и статистика:
- **Карточки:**
  - Жаңа пайдаланушылар (за месяц)
  - Аяқталу қарқыны (процент завершённости)
  - По мастер-хүіл (study/work/personal)

- **Прогресс модулей:** таблица с процентом завершённости
- **Графики:**
  - Распределение по мастер-хүіл
  - Распределение по возрастным группам

### 5. **Фидбек** (`/admin/feedback`)
Управление отзывами и рейтингами:
- Орташа баға (средний рейтинг) из всех пікірлер
- Фільтр по количеству звёзд (1-5)
- Список всех пікірлер:
  - Пайдаланушы + модуль
  - Звёзды + дата
  - Комментарий
  - Кнопка удаления

## Безопасность

Админка защищена двумя уровнями:

1. **Middleware проверка** (`src/middleware.ts`):
   - Проверяет `role = 'admin'` в таблице `profiles`
   - Неавторизованные пользователи → редирект на `/login`
   - Неадминисторы → показывает 404 (not-found)

2. **Роль-based access control (RBAC)**:
   - Используется поле `role` из таблицы `profiles`
   - Все админские страницы требуют `role = 'admin'`

## Структура базы данных

Админка использует эти таблицы Supabase:

- **profiles** — пользователи (id, email, name, role, goal, ...)
- **module_completions** — прогресс модулей (user_id, module_id, completed_at)
- **feedback** — пікірлер (user_id, module_id, rating, comment, created_at)
- **quiz_attempts** — попытки прохождения тестов (user_id, module_id, score, ...)

## Как использовать

### Запуск
```bash
npm run dev
# Админка доступна на http://localhost:3000/admin
```

### Создание админа
Чтобы дать пользователю доступ в админку:

```sql
-- Обновить role пользователя в profiles
UPDATE profiles 
SET role = 'admin' 
WHERE id = 'user-uuid';
```
